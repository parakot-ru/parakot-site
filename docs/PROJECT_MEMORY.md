## Правила работы

- Production не трогать без явной команды.
- Сначала тестировать и выкатывать на staging.
- При деплое лендинга не трогать `/api/` и `/uploads/`.
- При деплое API не затирать `.env` и CGI-настройки Beget.
- После изменений коммитить и пушить в `main`.
- Контент, который Костя меняет через продовую админку, не перетирать.

## Контент и секции

- Админка не должна превращаться в общий конструктор сайта.
- Админка разделена на экраны: Hero, пользовательские секции, контакты/заявки, общие настройки, SEO, справка.
- Вручную добавляются только обычные контентные секции.
- Первый экран редактируется как существующая hero-секция, а не создается заново.
- Контакты редактируются в отдельном разделе админки.
- Цены не выводим как самостоятельный смысл: Костя предпочитает договариваться лично.
- Основные стили секций: `rich_text`, `stats`, `cards_grid`, `locations_grid`, `timeline`, `gallery`, `faq`.
- `cards_two_columns` оставлен только для совместимости со старым контентом; в интерфейсе это обычные `Карточки`.
- `highlight` оставлен только для совместимости со старым контентом; в интерфейсе это обычные `Карточки` с одной колонкой.
- Для карточных секций количество колонок хранится в `sections.meta_json.columns`; на мобильных лендинг схлопывает карточки в одну колонку.

## Дизайн

- Тема: воздух, небо, горы, парапланы.
- Без лишних декоративных ярлыков и тяжелых эффектов.
- Hero должен быть презентабельным, но легким по ресурсам.
- Новостная лента нужна отдельно продумать; не впихивать ее механически на главную.
