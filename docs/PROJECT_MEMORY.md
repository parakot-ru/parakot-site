## Правила работы

- Production не трогать без явной команды.
- Сначала тестировать и выкатывать на staging.
- При деплое лендинга не трогать `/api/` и `/uploads/`.
- При деплое API не затирать `.env` и CGI-настройки Beget.
- После изменений коммитить и пушить в `main`.
- Контент, который Костя меняет через продовую админку, не перетирать.

## Контент и секции

- Админка не должна превращаться в общий конструктор сайта.
- Админка разделена на экраны: Hero, пользовательские секции, контакты, заявки, общие настройки, SEO, справка.
- Вручную добавляются только обычные контентные секции.
- Первый экран редактируется как существующая hero-секция, а не создается заново.
- Контакты редактируются в отдельном разделе админки.
- Цены не выводим как самостоятельный смысл: Костя предпочитает договариваться лично.
- Основные стили секций: `rich_text`, `cards_grid`, `locations_grid`, `timeline`, `gallery`, `faq`.
- `cards_two_columns` оставлен только для совместимости со старым контентом; в интерфейсе это обычные `Карточки`.
- `highlight` оставлен только для совместимости со старым контентом; в интерфейсе это обычные `Карточки` с одной колонкой.
- `stats` оставлен только для совместимости со старым контентом; в интерфейсе это обычные `Карточки` с видом `Числа`.
- Для карточных секций количество колонок хранится в `sections.meta_json.columns`, а вид карточек в `sections.meta_json.cardStyle`; на мобильных лендинг схлопывает карточки в одну колонку.
- Новостную ленту не впихивать механически на главную. Нужен отдельный раздел/страница `Новости`; на главной можно позже показать только короткий блок последних записей.

## Дизайн

- Тема: воздух, небо, горы, парапланы.
- Без лишних декоративных ярлыков и тяжелых эффектов.
- Hero должен быть презентабельным, но легким по ресурсам.
- Новостная лента нужна отдельно продумать; не впихивать ее механически на главную.

## Рабочие агенты

- Продукт-оунер: продает идеи, объясняет пользу пользователю и Косте, формулирует MVP и риски.
- Проверяющий идеи: режет scope, дает verdict `green` / `yellow` / `red`, предлагает дешевый staging-эксперимент.
- Маркетинг: отвечает за позиционирование, CTA, тексты, сезонность, новости и личный контакт без цен и пафоса.
- Дизайн-критик: ловит визуальный шум, случайный декор, плохую читаемость, слабый hero и мобильные проблемы.
- Генератор функционала и дизайна: накидывает функции, блоки, UI-паттерны, админские настройки и микроидеи.
- UX-протыкатель: проверяет удобство для мобильного посетителя, десктопного посетителя и Кости в админке.
- Для спорных решений сначала звать генератора/продукта, затем проверяющего идеи, дизайн-критика и UX-протыкателя.
