# Parakot Site

Монорепозиторий проекта `parakot.ru`.

## Структура

```text
landing/  - публичный лендинг
admin/    - React SPA-админка
api/      - PHP REST API
docs/     - ТЗ, архитектура и заметки по проекту
```

## Что внутри

- Лендинг читает управляемый контент из API.
- Админка управляет настройками, контактами, секциями, карточками и заявками.
- API хранит данные в MySQL и принимает заявки с формы.
- Seed-скрипты помогают быстро заполнить стартовый контент.

## Окружения и деплой

- `parakot.konekon.ru` и `admin.konekon.ru` - тестовое окружение для экспериментов.
- `parakot.ru` и `admin.parakot.ru` - production, рабочий сайт.
- По умолчанию любые изменения выкатываются только на тестовое окружение.
- Production нельзя трогать без явной команды: "выкатывай на прод", "обнови parakot.ru" или аналогичной.

Подробное правило деплоя: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Локальная работа

```bash
cd admin
npm install
npm run dev
```

Публичную часть можно смотреть напрямую:

```text
landing/index.html
```

Локальные секреты API лежат в `api/.env` и не попадают в git.
